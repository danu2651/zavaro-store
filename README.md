# ZAVARO — Collection 001

Updated warm-luxury frontend for the ZAVARO clothing brand.

## Included
- ZAVARO Collection 001 / Rebirth branding
- 11 product entries with product images from the supplied ZAVARO boards
- Product search and category filters
- Product detail modal with color + size selection
- Wishlist using localStorage
- Shopping bag using localStorage
- Responsive mobile layout
- Collection, color palette, details, headwear, story and packaging sections
- Warm ivory / espresso / taupe / subtle brass aesthetic preserved from the previous design
- Backend-ready product data in `script.js`

## Run
Open `index.html` in a browser.

## Future upgrade
The frontend is intentionally simple so the product array and checkout flow can later be connected to Node.js + PostgreSQL.
